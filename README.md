# 逆引きAS

アルタイル・シリウス用の技逆引きWebアプリです。
姉妹プロジェクトの逆引きPDと同じ3つの検索（技名、技AND、ポケモン名）に加えて、
コンテストのデータ（タイプ、アピール、ジャム、コンボ、ゲーム内説明文）を技ごとに表示します。

## 起動（ローカル）

JSONを読み込むため、ローカルHTTPサーバーから開きます。

```powershell
python -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/` を開いてください。

## 機能

### バージョン切り替え

アルタイル版とシリウス版では、習得技が違うポケモンがいます。画面上部で表示対象を選びます。

| 選択 | 表示される技 |
| --- | --- |
| 両方（初期値） | どちらか一方の版で覚える技。片方だけの技には「アルタイルのみ」「シリウスのみ」を表示 |
| アルタイル | アルタイル版のROMどおりの習得技だけ |
| シリウス | シリウス版のROMどおりの習得技だけ |

「両方」でも、版をまたいだ技の組み合わせは成立させません。
たとえば アスフィア は たたきつける をアルタイル版でのみ、のしかかり をシリウス版でのみ覚えるため、
AND検索「たたきつける ＋ のしかかり」の結果には出てきません。

### 技名 → 覚えるポケモン

技名を2文字以上入力すると、技情報カードと、覚えるポケモンの一覧を表示します。
部分一致が複数ある場合は候補チップが並び、クリックで切り替えられます。
一覧には、版名（片方の版のみのとき）と習得方法（レベル、わざマシン、教え技、タマゴ）を付けます。

技情報カードは、コンテストの情報を上に、バトルの情報を下に置きます。

- コンテスト: タイプ（かっこよさ、うつくしさ、かわいさ、かしこさ、たくましさ）、
  アピール（◎、赤）、ジャム（●、黒）、効果の分類、ゲーム内のコンテスト説明文、
  「この技から繋がる技」「この技に繋がる元の技」（クリックでその技へ移動）
- かけるのページ: 分類コード、効果、解説（折りたたみ）、コンボ先一覧
- バトル: タイプ、分類、威力、命中、PP、接触、バトル画面の技説明文
- 原作名: 技名を変えた技には「原作名: ○○」を付けます（下の「技名が変わった技」を参照）

### 技AND検索 → 両方覚えるポケモン

2つの技を入力すると、両方の技情報カードと、両方を覚えるポケモンの一覧を表示します。

### ポケモン名 → 覚える技

ポケモン名を入力すると、タイプ、特性、体重、種族値と、覚える技の一覧を表示します。
アスフィアのように版で中身が違うポケモンは、アルタイルとシリウスを横に並べて表示します。

各技の行には、コンテストタイプ（色つきバッジ）、◎と●の数、タイプ、分類、威力、命中を出します。
行をクリックすると、技情報カードが開きます。

- 技名・ローマ字・タイプ・コンテストタイプの文字で絞り込み
- コンテストタイプのボタン（かっこよさ、うつくしさ、かわいさ、かしこさ、たくましさ）で絞り込み。もう一度押すと解除
- 並び順: 習得テーブル順、アピールが高い順、アピールが低い順、威力が高い順

### コンテストタイプで技を探す

タイプのボタンを選ぶと、そのタイプの技をアピールが高い順（同じならジャムが少ない順）に並べます。
行をクリックすると、技情報カードが開きます。

### 入力について

- 技名・ポケモン名は カタカナ / ひらがな / ローマ字 のどれでも検索できます
  （`エナジーボール` = `えなじーぼーる` = `enaji-bo-ru` のように、読みで引けます。長音は `-`）
- 2文字以上の入力、300msの入力停止後に検索します
- 完全一致、前方一致、部分一致の順に候補を並べます
- 技名の検索では、原作名の部分一致も候補に入ります

## 表示ルール

| 表示 | 元データ |
| --- | --- |
| ◎ | `contest.appeal` の数だけ並べる（赤） |
| ● | `contest.jam` の数だけ並べる（黒） |
| 説明文（コンテスト） | `description`（コンテスト画面で出る文） |
| 説明文（バトル） | `battle_description`（ステータス画面で出る文） |
| 分類 物理 / 特殊 | `category`。第3世代のタイプ別分類（威力が0の技は「変化」と表示） |
| 威力 `—` | `power` が 0 |
| 命中 `必中` | `accuracy` が 0 |
| 原作名 | `vanilla_name`。技名を変えた技にだけ付く |

### 技名が変わった技

このハックは、原作（エメラルド）の技のうち30個の技IDを、別の技に作り替えています
（例: ハサミギロチン が ダストシュート に、クラブハンマー が エナジーボール に）。
ただし、コンテスト用のデータ（タイプ、アピール、ジャム、コンボ、説明文）はROM内で元の技のままです。
そのため、これらの技のコンテスト情報は、見た目の技ではなく原作の技のものになります。
該当する技には「原作名」を表示し、注記のツールチップで説明しています。
一覧は `data_meta.json` の `renamed_moves` にあります。

### 版で違うポケモン

アスフィアは、アルタイル版とシリウス版で種族値、タイプ、図鑑説明、習得技が違います。
データの最上位はアルタイル版で、シリウス版の値は `sirius` に入っています。
ほかのポケモンは両版で同じです。

### ポケモンのリンク

wikiが自動アクセスを受け付けないため、リンク用のデータはありません。
ポケモン名は文字だけで表示します。
`pokemon_links.json`（ポケモン名 → URL）をリポジトリ直下に置くと、読み込んでリンクにします。
ファイルがなくても、画面は問題なく動きます。

## テスト

Node.js 20以降で実行します。

```powershell
npm install
npm test
```

jsdomで `index.html` と `app.js` を実際に読み込み、`node:test` で次を検証しています。

- データの件数と必須フィールド
- 技検索のカードにコンテスト情報、かけるのデータ、原作名が出ること
- AND検索で、版をまたぐ組み合わせが成立しないこと（アスフィアの限定技を使用）
- アスフィアの版差分ブロック
- コンテストタイプでの絞り込み、並べ替え、「コンテストタイプで技を探す」

## 構成

- `index.html`: 画面
- `searchmove_style.css`: レイアウト
- `app.js`: 検索と表示
- `pokemon_moves.json`: 技データ354件（バトルの数値、説明文、コンテストデータ、かけるのページのデータ）
- `all_pokemon_data.json`: ポケモンデータ203体（種族値、タイプ、特性、体重、習得技、図鑑説明）
  - `moves` / `move_ids`: 両版の和集合、`altair_only` / `sirius_only`（`*_ids`）: 片方の版でしか覚えない技
  - アルタイル版の習得技 = `moves` − `sirius_only`、シリウス版 = `moves` − `altair_only`
  - `learn`: レベル、わざマシン、教え技、タマゴ技
  - `version_differs: true` のポケモンは `sirius` に、シリウス版の値を持つ
- `contest_effects.json`: コンテスト効果48種（分類、アピール、ジャム、説明文）
- `data_meta.json`: 件数、原作名つきの技の一覧、メモ
- `tools/`: データ生成スクリプト（下記）
- `test/ui.test.js`: jsdomによる表示テスト

## データの作り直し

ROMから `pokemon_moves.json` などを作り直すスクリプトを `tools/` に置いています。
Python 3 が必要です。

```powershell
# 1. かけるのページのHTMLを保存したフォルダから、かける用JSONを作る
python -X utf8 tools/parse_kakeru.py <保存したHTMLのフォルダ> kakeru_contest.json

# 2. ROMから各JSONを作る
python -X utf8 tools/extract_as_data.py `
  --rom-dir <ROMのフォルダ> `
  --charmap <charmap.tbl> `
  --vanilla-rom <エメラルドのROM> `
  --kakeru kakeru_contest.json `
  --out .
```

`extract_as_data.py` の引数

| 引数 | 内容 | 省略時 |
| --- | --- | --- |
| `--rom-dir` | `18年1月30日完成版アルタイル.gba` と `18年1月30日完成版シリウス.gba` があるフォルダ | `gyakubikiAS` の隣の `org/` |
| `--charmap` | 文字コード表 `charmap.tbl` | `pokehack/NeoDark-CFRU-main/charmap.tbl` |
| `--vanilla-rom` | 原作（エメラルド日本語版）のROM。技名を変えた技の `vanilla_name` に使います。ファイルがなければ `vanilla_name` は空になります | `pokehack/ROM/Pokemon Emerald (J)/` 内の既定の場所 |
| `--kakeru` | `parse_kakeru.py` が作ったJSON。省略すると `kakeru` を付けません | なし |
| `--out` | 出力先 | `gyakubikiAS` |

`parse_kakeru.py` の引数は、保存したHTMLのフォルダ（`index.htm`、`reference.htm`、コンボのページ）と、出力JSONのパスです。
ROMは読み込むだけで、書き換えません。

- `tools/extract_as_data.py`: ROMから技、ポケモン、コンテスト効果、メタ情報のJSONを作成
- `tools/gba_text.py`: 第3世代の日本語文字コードの変換
- `tools/kana.py`: ひらがな、ローマ字の変換
- `tools/parse_kakeru.py`: かけるのページのHTMLからJSONを作成

## データ出典

- 技、ポケモン、習得技、コンテストのデータ: アルタイル版・シリウス版のROM（18年1月30日完成版）から抽出
  - コンテストのタイプ、アピール、ジャム、コンボ、説明文はROM内のコンテスト用テーブルと文字列
- コンテストの効果分類、解説、コンボ先一覧:
  [かけるのページ 効果別コンテスト技リスト](https://www2u.biglobe.ne.jp/~kakeru/pokemon_a/contest/)
  （技名を変えた技は、変更前の技名で対応づけています）
- 画面構成の参照元: 逆引きPD（[pit-true/gyakubikiPD](https://github.com/pit-true/gyakubikiPD)）
